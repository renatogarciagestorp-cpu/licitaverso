 Accessibility

 Epilepsy Safe Mode 

Epilepsy Safe Mode

Dampens color and removes blinks

This mode enables people with epilepsy to use the website safely by eliminating the risk of seizures that result from flashing or blinking animations and risky color combinations.

 Visually Impaired Mode 

Visually Impaired Mode

Improves website's visuals

This mode adjusts the website for the convenience of users with visual impairments such as Degrading Eyesight, Tunnel Vision, Cataract, Glaucoma, and others.

 Cognitive Disability Mode 

Cognitive Disability Mode

Helps to focus on specific content

This mode provides different assistive options to help users with cognitive impairments such as Dyslexia, Autism, CVA, and others, to focus on the essential elements of the website more easily.

 ADHD Friendly Mode 

ADHD Friendly Mode

Reduces distractions and improve focus

This mode helps users with ADHD and Neurodevelopmental disorders to read, browse, and focus on the main website elements more easily while significantly reducing distractions.

 Blindness Mode 

Blindness Mode

Allows using the site with your screen-reader

This mode configures the website to be compatible with screen-readers such as JAWS, NVDA, VoiceOver, and TalkBack. A screen-reader is software for blind users that is installed on a computer and smartphone, and websites must be compatible with it.

 Procuradoria-Geral Do Estado Do Piauí Accessibility Statement

Aqui está a tradução do texto em um Português do Brasil claro, acessível e de fácil leitura: 

 Declaração de Acessibilidade
 www.pge.pi.gov.br
 17/11/2026 

Compromisso com a acessibilidade 

Acreditamos que a internet deve ser acessível para todas as pessoas, independentemente de suas condições ou habilidades. Por isso, temos o compromisso de oferecer um site que possa ser usado pelo maior número possível de pessoas. 

Para garantir isso, seguimos ao máximo as Diretrizes de Acessibilidade para Conteúdo Web 2.1 (WCAG 2.1) no nível AA, criadas pelo W3C (World Wide Web Consortium). Essas diretrizes ajudam a tornar os sites acessíveis para pessoas com deficiências visuais, motoras, cognitivas, entre outras. 

Nosso site usa diferentes tecnologias para estar sempre acessível. Temos uma interface de acessibilidade que permite que usuários com necessidades específicas ajustem o visual e funcionamento do site conforme suas preferências. 

Além disso, utilizamos uma aplicação com inteligência artificial que trabalha em segundo plano para melhorar continuamente a acessibilidade. Essa ferramenta ajusta o HTML do site, adapta sua funcionalidade para leitores de tela e permite navegação apenas com o teclado. 

Se você encontrou algum erro ou tem sugestões de melhoria, entre em contato conosco pelo e-mail: pge@pge.pi.gov.br. 

Leitores de Tela e Navegação por Teclado 

Nosso site utiliza atributos ARIA (Aplicações Ricas Acessíveis na Internet) e outros recursos para garantir que usuários cegos possam navegar e interagir com o conteúdo usando leitores de tela. 

Assim que um usuário com leitor de tela acessa o site, aparece uma sugestão para ativar o "Modo Leitor de Tela", o que facilita a navegação. Veja o que fazemos para garantir essa acessibilidade: 

 Otimização para leitores de tela:
Executamos um processo em segundo plano que analisa o conteúdo do site e garante que ele funcione com leitores como JAWS e NVDA. Esse processo adiciona rótulos em formulários, descrições em ícones (como redes sociais, busca, carrinho etc.), orientações de preenchimento, e muito mais. 

As imagens são escaneadas para gerar descrições alternativas (ALT) com base em reconhecimento de objetos, além de capturar textos inseridos nas imagens usando tecnologia de OCR (reconhecimento óptico de caracteres). 

Para ativar os ajustes de leitor de tela, basta pressionar Alt+1. Essa função também é sugerida automaticamente ao entrar no site. 

 Navegação por teclado:
O processo também adapta o site para navegação com o teclado. Você pode: 

Navegar com Tab e Shift+Tab 

Usar setas para menus suspensos 

Fechar menus com Esc 

Usar Enter para ativar botões e links 

Navegar entre opções com as setas e selecionar com Espaço ou Enter 

Acessar menus de navegação rápida com Alt+1 ou diretamente ao iniciar navegação por teclado 

Atalhos de navegação: 

 M para menus 

 H para títulos 

 F para formulários 

 B para botões 

 G para imagens 

Perfis de acessibilidade disponíveis no site 

 Modo Seguro para Epilepsia: desativa animações e combinações de cores que podem causar crises epilépticas. 

 Modo para Deficiência Visual: adapta o site para pessoas com visão reduzida, como visão em túnel, catarata, glaucoma etc. 

 Modo para Deficiência Cognitiva: oferece recursos para facilitar a navegação para pessoas com dislexia, autismo, AVC, entre outros. 

 Modo para TDAH: reduz distrações e ajuda a manter o foco nos principais elementos do site. 

 Modo para Cegueira: configura o site para leitores de tela como JAWS, NVDA, VoiceOver e TalkBack. 

 Perfil de Navegação por Teclado (Deficiência Motora): permite o uso completo do site apenas com o teclado, com suporte aos atalhos já mencionados. 

Ajustes adicionais de interface e leitura 

 Fonte: é possível aumentar ou diminuir o tamanho, mudar o tipo da letra, ajustar espaçamento, alinhamento e altura da linha. 

 Cores: usuários podem escolher entre contrastes claros, escuros, invertidos ou monocromáticos. Também é possível personalizar as cores de texto, fundo e títulos com mais de 7 opções. 

 Animações: pessoas com epilepsia podem desativar todas as animações com um clique (vídeos, GIFs, transições CSS). 

 Destaque de conteúdo: é possível destacar elementos importantes como links e títulos, ou realçar apenas o item selecionado. 

 Silenciar Áudio: desativa sons automáticos para evitar desconforto a usuários com aparelhos auditivos. 

 Apoio Cognitivo: oferece um mecanismo de busca ligado à Wikipedia e ao Wikicionário para entender expressões, siglas e gírias. 

 Outras funções: mudar o tamanho e cor do cursor, ativar teclado virtual, modo de impressão e muito mais. 

Compatibilidade com navegadores e tecnologias assistivas 

Buscamos garantir compatibilidade com os principais navegadores e tecnologias de apoio, como: 

Navegadores: Google Chrome, Mozilla Firefox, Apple Safari, Opera, Microsoft Edge 

Leitores de tela: JAWS, NVDA 

Esses sistemas representam mais de 95% dos usuários da internet. 

Observações e contato 

Apesar dos nossos maiores esforços para garantir um site totalmente acessível, pode haver páginas ou seções ainda em processo de adaptação. Continuamos trabalhando constantemente para melhorar, atualizar e desenvolver novas soluções de acessibilidade. 

Se precisar de ajuda ou quiser enviar sugestões, entre em contato conosco pelo e-mail: pge@pge.pi.gov.br.
